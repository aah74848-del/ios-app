# KurdUnity Launcher (iOS)

A minimal native launcher for the KurdUnity SA-MP setup, built to be compiled
**without a Mac** (via a cloud macOS runner) and installed on iPhone with **ESign**.

- Objective-C / UIKit, programmatic UI (no storyboard, no Swift).
- Nickname field, **PC host** field, **PLAY** button.
- **Nickname and PC host are saved continuously** (on every keystroke) to
  `NSUserDefaults` and to `Documents/samp/settings.ini`:
  ```ini
  [client]
  name=<nickname>
  host=134.255.220.191
  port=7777
  [stream]
  pc=<pc host>
  ```
- **SERVER** line: a real RakNet "unconnected ping" query to `134.255.220.191:7777`
  shows whether the server responds, its name, and player counts (`SAMPQuery`).
- **GTA STATUS**: a download-style progress bar that walks through load phases.
- **PLAY** runs a SA-MP-style join sequence (`Connecting → Joining as <nick> →
  Logged in`), copies the server address, then hands off to a streaming client.
- **Get / open Moonlight**: opens the Moonlight App Store page.
- **Download SA-MP client (PC)**: a real download of the free, official
  `sa-mp-0.3.7-R5-2-MP` installer with a live progress bar. It tries several
  public mirrors, saves to `Documents/KurdUnity/`, and opens a share sheet so the
  installer can be moved to the player's Windows PC. (It's a Windows `.exe`; iOS
  cannot run it.)
- Hardcoded server: `134.255.220.191:7777`.

> Playback note: this launcher does **not** run SA-MP itself. On a non-jailbroken
> iPhone, SA-MP is played by **streaming** a PC-hosted session (see the parent
> `../IOS-SAMP-PLAN.md`). The server query is real; the "join" is the launcher's
> staged UX. **Moonlight iOS registers no URL scheme**, so a fully automatic
> one-tap launch into a stream is not possible — the launcher copies the server
> address and opens Moonlight's App Store page instead.

## How "SA-MP on iPhone" actually works (streaming)
1. **Host PC**: install **GTA: San Andreas v1.00 (US)**, then the **SA-MP 0.3.7**
   client (use the in-app download), and install **Sunshine** (game stream host).
2. **iPhone**: install **Moonlight** from the App Store.
3. Pair Moonlight with the PC (enter the PC host, e.g. `192.168.1.20`, in both the
   launcher and Moonlight). Add GTA:SA as an app in Sunshine.
4. In the launcher: tap **PLAY** → it copies `134.255.220.191:7777` and offers to
   open Moonlight → start the stream → paste/join the server in-game.


## Why no `.xcodeproj` is committed
The project is defined in [`project.yml`](project.yml) and generated by
[XcodeGen](https://github.com/yonaskolb/XcodeGen) at build time. That keeps the
repo Mac-free and avoids fragile, hand-written project files.

## Build without a Mac (GitHub Actions)
1. Push this folder to a GitHub repository (`main` branch).
2. The workflow [`.github/workflows/build-ipa.yml`](.github/workflows/build-ipa.yml)
   runs on a `macos-14` runner, generates the project, builds an **unsigned** app,
   and uploads `KurdUnityLauncher.ipa` as a build artifact.
3. Download the artifact from the Actions run.

## Build on a Mac (alternative)
```bash
brew install xcodegen
bash build-ipa.sh
# -> KurdUnityLauncher.ipa
```

## Install with ESign
1. Transfer `KurdUnityLauncher.ipa` to the iPhone (AirDrop / Files / iCloud).
2. Open **ESign** → Import the IPA.
3. Tap the IPA → **Sign (توقيع)** → choose your certificate → **Sign**.
4. Install, then trust the certificate: **Settings → General → VPN & Device Management**.
5. Open the launcher, type a nickname, tap **PLAY**.

## Files
```
project.yml                       XcodeGen spec (app target, INFOPLIST_FILE)
Launcher/Info.plist               committed app Info.plist
Launcher/main.m                   entry point
Launcher/AppDelegate.h/.m         window + root VC
Launcher/LaunchViewController.h/.m  the launcher UI + settings.ini writer + handoff
Launcher/SAMPQuery.h/.m           real RakNet server status query
Launcher/SAMPDownloader.h/.m      real SA-MP client downloader (mirrors + progress)
build-ipa.sh                      macOS/CI build script -> unsigned .ipa
.github/workflows/build-ipa.yml   cloud-Mac build
```

## Caveats
- The built IPA is unsigned by design; ESign supplies the signature/entitlements.
- A free/enterprise ESign certificate has expiry + device-limit constraints.
- SA-MP needs **GTA:SA v1.0 (US)** on the host PC to connect to `134.255.220.191:7777`.
